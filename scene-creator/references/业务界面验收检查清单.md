# 业务界面验收检查清单

> 本文是 `SKILL.md` 的业务界面验收指南。完成本地交互检查并取得部署终态后读取；页面能打开或请求已受理都不能替代这里要求的证据。

---

在业务界面完成本地检查并部署后执行本清单。验收依据是当前场景包和 Workflow 资产、实际源码包、模板检查结果及部署终态，不以 Agent 自述或“页面能打开”代替证据。

## 绑定与契约

- `goalfy-app.json.scenario_pack_id` 等于本工单的真实场景包 ID。
- 当前场景包至少挂载一个真实 Workflow；纯 SA 或只有普通任务点的场景包没有绕过当前 UI 工具门槛。
- 界面涉及的 Workflow slug、input/output Schema 来自当前线上资产，不来自 Demo、历史文档或记忆。
- 单 Workflow 仅在模板 SDK 明确支持时使用 `workflow.list/run`；2.0 多路线图只有在宿主公开匹配版本的 Business/Runtime 启动、状态、交互和 Delivery Review 能力时使用。
- 编排形状来自实时 Schema 和版本化服务端契约，没有混入设计稿、集成分支或旧资产中的未来字段。
- `schema/workflows/` 只包含本场景包真实契约，文件名与 slug 一致。
- 记录的 `ui_contract_snapshot` 与部署时场景包、Workflow 和 orchestration 版本一致。
- 页面发现契约缺失、revision 漂移或不兼容时停止结构化提交并回落聊天，不自行补字段。

## 源码与 SDK 边界

- 开发起点有本工单 `download_template` 的成功响应；模板实际字节数与响应一致，且安全解压到新的独立目录。
- 唯一开发目录由 `goalfy-app.json` 定位，不是通用 `init_project`、Git 克隆、历史模板或手工空目录。
- 根 `AGENTS.md`、`README.md`、`schema/README.md` 和 `src/sdk/docs/README.md` 已完整读取；`template_identity` 不含下载短链。
- 业务代码只修改模板允许的页面和组件；固定 SDK、启动、桥协议和错误边界未被绕过。
- 平台能力只通过当前模板 SDK 使用，不存在直接平台 `fetch`、存储凭证、访问父窗口或自造 postMessage。
- 业务界面没有暴露 MCP 工具、Toolset、FastAgent、提示词、脚本、DAG 或内部控制动作。
- manifest 声明的 capabilities 覆盖源码实际使用能力，未申请无关能力。
- 源码不含用户身份、密钥、Cookie、预签名 URL、构建机路径、固定 `/workspace` 输入路径或测试场景包 ID。

## 交互和业务完成度

- 必填、枚举、数值、日期、文件、图片、数组和对象字段按真实 Schema 提供可用控件；复杂结构未偷懒降级为不可用文本框。
- 文件上传后提交 SDK 返回的当前项目 Workspace 路径，不提交文件名、本地路径或 URL。
- 只读协作者、项目执行中、等待用户、失败和完成状态有清晰反馈和正确禁用策略。
- 提交成功只显示“已受理”，不会误报“执行完成”；最终状态和结果来自宿主状态与消息。
- 页面刷新、主题切换、空数据、错误和回落聊天路径可用。

## 构建和发布证据

- 模板要求的类型检查、lint、测试和 build 全部通过。
- mock 交互至少覆盖真实主路径：输入、上传（如有）、提交、运行中状态和结果展示。
- 正式源码包已删除 Demo 页面、演示路由、演示契约、占位文案、`node_modules`、`dist`、`.git` 和 `.env*`。
- `size_bytes` 与实际压缩包一致，`source_sha256` 是实际压缩包字节的 64 位小写 SHA256。
- `prepare_upload → PUT → complete_upload → deploy/status` 使用同一工单和场景包；部署到达明确终态。
- `scene_package_ui_bundle(get)` 反读到当前源码包及成功激活地址。

## 裁决和输出

- 任一绑定错误、契约漂移、SDK 越界、Demo 残留、构建失败或部署非成功终态都裁决为 `blocked`。
- 模板缺少当前编排版本所需顶层运行能力时裁决为 `platform_blocked`，不得用单 Workflow `workflow.run` 假装执行整包编排。
- 通过时输出并写入工单：`passed`、场景包 ID、契约摘要、源码 SHA256、deployment_id、激活地址和已覆盖交互。
- 同时列出模板身份、未做真实全链路运行、未覆盖复杂控件或宿主能力等剩余盲区。
