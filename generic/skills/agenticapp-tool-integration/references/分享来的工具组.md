# 分享来的工具组

开发者说的工具组是别人分享来的，搜不到、看不到参数，或要判断能不能改它时读。

- **搜不到**：分享来的工具组名字常和开发者说的不一样，先用开发者给的工具名、平台名的英文短词再试；还搜不到，在「要你做的」里请开发者给工具组 ID（开发者中心资产页或分享消息里能看到），或请分享人再分享一次。拿到 ID 后 `get_asset` 看权限。
- **看不到参数**（`get_asset` 配置为空且 `can_view_params=false`、工具列表为空）：这是权限脱敏，不是空资产。先用 `otpe_tool_test` 按工具描述或开发者给的样例里能看出的参数取样一次；调用被拒或返回参数错误时，按报错提示补参数再试一次。仍拿不到真实返回的，在制作中第一次真跑时核实（PRD 里怎么写见 `agenticapp-stage-1-requirements`）。
- 不能克隆的分享资产按原样用，不改它；分享人收回或改动后，用到它的步骤会停。
