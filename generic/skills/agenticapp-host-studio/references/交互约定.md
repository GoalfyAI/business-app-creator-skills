# 开发文档里的交互约定

想知道生成的页面能做什么、不能做什么，或开发者问「文档里的按钮怎么点不动」时读。这也是 Studio 显示开发文档时要满足的约定。

## 页面有哪些交互

| 文档 | 交互 | 没有脚本时 |
|---|---|---|
| 需求说明 | 流程图连线；点节点在下面看输入、输出、重要信息；按环节跳转；上一个、下一个 | 流程图没有连线，节点按编号排；每个节点的详情在图下按环节列出 |
| 方案 | Demo 按栏宽缩放、可以操作；点编号高亮下面对应的说明；重置示例；Demo 左侧导航跳到别的功能 | Demo 显示静态页面，点不动；编号和说明照样对得上 |
| 制作进度 | 时间轴回放 | 时间轴照常显示 |
| 验收报告 | 选一条路径看；点某一步看依据；回放这条路径 | 全部路径依次列出 |

现在的 Studio 显示开发文档时会删掉脚本，页面按「没有脚本时」那一列显示，内容一样完整。Studio 放开文档脚本之后，交互自动可用，不用重新生成。

## 页面不会做的事

生成的页面和 Demo 都只在自己页面里运行：

- 不联网：不请求任何地址，不加载外部脚本、样式、字体、图片；
- 不存东西：不用浏览器存储，刷新或点「重置示例」回到初始状态；
- 不碰宿主：不访问父窗口，不弹窗，不跳转页面，链接只在页内跳转；
- 不提交表单：没有 `<form>`，按钮只改页面里的显示。

Demo 里点「保存」只是示例，不会写进任何数据；进度、验收的回放只按已有记录亮一遍，不重新测试。

## 给 Studio 的显示要求

页面能运行交互需要 Studio 这样显示（Studio 方的改动，不是你的事；开发者问起交互不可用时，按这里说明原因，不请他改设置）：

- 在独立的源里运行页面脚本：iframe 允许脚本，但不和 Studio 同源，脚本拿不到宿主的权限和数据；
- 内容安全策略放行内联脚本和内联样式，其余照旧：`default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:; font-src data:; connect-src 'none'; form-action 'none'; base-uri 'none'`；
- 截图仍按 `shots/` 文件随文档保存、显示时换成内嵌图片；
- 页内锚点在页面里滚动；阅读位置照旧按文档记住。
