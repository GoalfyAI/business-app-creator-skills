# A5 发布与交付（骨架 · 待发布链路定稿后成文）

## 骨架（正文待写）

1. 版本发布：应用独立版本，**显式记录所依赖的场景包版本**；发布版不能下线，普通版可下线；
2. 用户首次打开时的真正部署语义（copy schema + 替换 env + P2S）与静默缩容，在交付报告中向开发者说明；
3. 交付报告结论先行：应用名称与版本、依赖的场景包版本、四类页面清单、验收结果（效果结论：清单通过情况 / 遗留问题 / 明说的盲区）；
4. 上线授权由开发者给出后执行；结单前结果检查表快照全绿。

## 出口条件（骨架）

- 发布完成并反读线上状态；交付报告交付；工单结单；落 `stage_exit`。
