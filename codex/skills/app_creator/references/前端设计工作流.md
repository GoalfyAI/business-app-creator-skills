# 前端设计工作流

前端界面的设计与构建方法论正本（原独立 skill `frontend-product-studio`，2026-09-01 并入本 Skill）。在 A1 产品设计与 A3 前端实现全程使用；自主推进、给出并简述合理的设计假设，不就常规设计选项询问用户。本文是编排层，不内嵌教学内容——四份官方 guidance 的**完整钉版副本**随本 Skill 分发在 [前端设计指南/](前端设计指南/)，按下表在执行时按需读取。

## 2. 七步工作流

1. **理解产品**：查仓库、现有 UI、截图、内容与项目约束，确立——用户是谁、要完成什么、认哪些业务词；入口、首个决策、主行动、成功态、恢复路径；加载/空/错误/权限/破坏性/长内容/移动各状态；既有框架、token、无障碍约定与可复用组件。先用产品认知 guidance，***不从装饰或组件画廊起手***。
2. **定一个有辨识度的方向**：贴合主题的设计主张、配色、字体系统、布局逻辑、密度与一个记忆点；对着产品真实任务校验后再编码。避开 AI 通用默认与无由装饰；用真实界面文案；表达再有个性，主行动与信息层级必须一眼可辨。
3. **设计完整交互**：画出从入口到完成的最短连贯旅程；打磨快乐路径之前先定义所有重要状态；移动端保证主行动可达、核心任务优先。
4. **用精选组件构建**：只从 MIT 白名单取用成熟组件——Magic UI / Cult UI / KokonutUI / shadcn/ui；***不从 Aceternity、ReactBits、Vue Bits、Tremor、21st.dev 或名单外的库取代码***。一屏至多一个主视觉件；取来的组件必须适配项目 token、响应式、内容、性能与 `prefers-reduced-motion`，不原样出厂。
5. **打磨交互工艺**：主流程跑通后审动效——每个动效有目的吗、高频操作该不该即时、缓动时长是否跟手、按压/悬停/聚焦状态是否一致、过渡能否被安全打断。偏向体感速度与直接反馈；删掉拖慢重复操作、与主任务抢注意力、只为热闹的动效。
6. **真实渲染、走一遍、再修一轮**：跑起来用浏览器工具看真实渲染结果；桌面与移动各过主旅程和相关非正常态；查键盘导航、可见焦点、对比度、触控目标、长文本、溢出、减少动效。先修结构问题再修装饰问题；***至少完成一轮渲染页修正，不许只看源码就宣布完成***。
7. **交付**：汇报实现结果、关键设计决策、实际使用的组件来源、做过的验证与真实的遗留局限。

## 3. 冲突规则

- 用户明确要求与仓库约束 > 一切 guidance 建议；
- 产品清晰与任务完成 > 视觉新奇；
- 无障碍与减少动效 > 动画偏好；
- 本文的 MIT 白名单 > guidance 目录中的更大清单（`components.json` 只在白名单四库范围内取用）。
