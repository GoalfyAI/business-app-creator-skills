# 确认页：一页说清，一次确认

发给用户的只有这一页。用用户的词，不出现 FA、TPE、工具集、Runtime。

```
## <应用名>

**它帮你做什么**：一句话。

**功能清单**
1. <功能一>：用户在哪里点什么，得到什么
2. <功能二>
3. 数据管理：可以看和改哪些表

**分工表**
<每条路线一张表，来自 design/分工表.md>

**会存下来的东西**
| 对象 | 存在哪张表 | 谁能改 |
|---|---|---|
| 广告主清单 | advertisers | 系统写，用户只看 |
| 停投名单 | stop_decisions | 用户写 |

**做不成的时候**
<把分工表第四列汇总成三句话>

**费用与副作用**
- 会调用：<外部工具名>，每次约 <费用>
- 会写入 / 发送：<有就写，没有写「不会向外发送任何东西」>

**上线范围**
- 先在开发者预览验收，你说可以再发布到目录
- 用的人：<谁>
```

规则：

- 用户回复「可以」或等价表述即视为确认，进加速模式；回复里有改动就改表，改完不用再问一遍，直接做。
- 简单应用不写分工表，只写功能清单、会存下来的东西、上线范围三段。
- 费用与副作用这一段不能省。
