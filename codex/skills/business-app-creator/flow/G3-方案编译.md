# G3 方案编译

把确认页（含分工表）逐行编译成要造的东西：资产清单、路线草图、表清单、页面清单。编译结果是 G4、G5 的施工单，用户不需要看懂它。

## 1. 进入条件

- G2 出口：确认页每一步都有复用资产、新建或已决定的处置。
- 从修订进来时，只编译受影响的行。

## 2. 做什么

1. **逐行映射**（顺序固定：工具集 → FA → 编排型 TPE → 路线）：

   | 确认页 / 分工表 | 变成 | 备注 |
   |---|---|---|
   | 规则行 | 编排脚本里的一步 `await tool(…)`；写库经数据集 FA 或后端接口 | 脚本按 [../reference/编排脚本.md](../reference/编排脚本.md) 三种模板之一改 |
   | 模型行 | 一个 FastAgent（复用或新建） | 输出对象每个字段含义、非成功状态（`needs_input`、`insufficient_evidence` 等）在这里定 |
   | 人行 · 触发 | 路线入口表单 | 入口字段 = 用户要填的东西；`assemble` 会把上游没提供的字段放进入口 |
   | 人行 · 中途补信息 | 节点级运行中交互 | 只把表单值写进尚未派发的下游字段，见 [../reference/业务路线.md](../reference/业务路线.md) |
   | 人行 · 审阅结果 | 路线 `delivery.review` | 缺省 `user_gate`；要「修改后重跑」加跳转到另一条路线 |
   | 进什么出什么 | TPE 的 `input_schema` / `output_schema`，以及模板表 | 字段名用英文蛇形，含义写进 `description`；文件用 `format: workspace-file-path` |
   | 做不成怎么办 · 停下来 | 让异常冒泡 | 平台按失败类别归因并告知用户 |
   | 做不成怎么办 · 标记继续 | `try/except` 只包那一次 `tool()`，输出带 `status` 与 `warnings` | 读 `e.recoverable` 决定写法 |
   | 做不成怎么办 · 重试一次 | 同上，except 里再调一次 | 工具内部已重试的不再叠加 |
   | 会存下来的东西 | 数据模板里的表与列 | 每列定 `user / agent / system`，见 [../reference/数据模板.md](../reference/数据模板.md) |
   | 功能清单里的页面 | 预置件或 `gen:pages` 生成页 | 见 [../reference/前端页面.md](../reference/前端页面.md) |

2. **定路线数**：一条业务路线通常一条编排型 TPE 就够；要中途表单、并行或节点级接管才拆多条。只有规则步骤的应用也建一条最小路线。
3. **定数据怎么进出**：每个业务输入从哪来（入口表单 / 读应用库 / 两者兜底），每个产出写到哪（更新已建行 / 回流建新行），见 [../reference/数据模板.md](../reference/数据模板.md)「谁建行」。
4. **核对费用与副作用**：会调的收费工具、会写或发出去的东西，与确认页那一段一致；多出来的回 G1 补确认。
5. **只有规则步骤时**：编译结果写一行「一条最小路线 + N 张表 + 数据页」即可，不展开。

## 3. 产出与落盘

编译结果写进本段阶段文档，并记工单 checkpoint：

| 清单 | 每项写什么 |
|---|---|
| 资产清单 | 类型、名称、复用还是新建、来源资产 ID |
| 路线草图 | 每条路线：`orchestration_id`、节点顺序、入口字段、中途表单、审阅方式 |
| 表清单 | 表名、列、每列可编辑性、唯一键、谁建行 |
| 页面清单 | 预置件 / 生成页 / 定制页，各自读写哪张表或哪条路线 |

方案页更新「怎么做」一节：用业务语言说有几条路线、存几张表、几个页面。阶段状态：G3 `passed`，G4 `in_progress`。

## 4. 给开发者看什么

一句话：「按你确认的内容，要做 N 条路线、M 张表、K 个页面，开始制作。」编译结果与确认页一致时不需要开发者再确认。

## 5. 出口

确认页每一行在编译结果里都能找到对应项，且费用与副作用没有超出确认页。

## 6. 出问题怎么办

| 现象 | 先看 | 回到 |
|---|---|---|
| 某一行编译不出来（没有对应能力） | G2 对照表 | G2 |
| 编译后费用或副作用超出确认页 | 确认页「费用与副作用」 | G1 补确认 |
| 一条路线超过 8 步 | 分工表填写规则 | 拆成两条路线，改确认页 |
