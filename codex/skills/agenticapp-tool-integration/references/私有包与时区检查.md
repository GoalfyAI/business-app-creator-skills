# 私有包与时区检查

开发者提供本地包要上传成工具组时读。

## 为什么走上传

预览工具运行在独立服务里，访问不到你本地的文件系统，给它传本地文件路径没有用。私有包走：

```text
1. file_to_url                      把本地包交给平台，声明对应用途
2. upload_and_register_tool_group   用返回的文件引用注册，同样支持前置安装步骤
```

## 时区数据

平台运行私有包的环境没有系统时区数据，开发者本机一般有，所以本机能跑不代表平台能跑：

- 包里用到 `zoneinfo` 时，在 `pyproject.toml` 的 `dependencies` 里声明 `tzdata`；不用时区的包不加。
- 上传前模拟没有系统时区数据的环境，真实调用一次用到时区的工具：

  ```text
  { cat calls.jsonl; sleep 5; } | PYTHONTZPATH= uvx --from <本地 wheel> <入口命令>
  ```

  `calls.jsonl` 依次是 `initialize`、`notifications/initialized`、`tools/call` 三行 JSON-RPC。送完后标准输入要再保持打开几秒（上面的 `sleep 5`）；输入一结束就关闭，进程可能来不及返回 `tools/call` 的响应。
- 收到 `tools/call` 的响应且 `isError` 不为 `true` 才算通过；进程提前退出、没有 `tools/call` 响应、`isError: true` 都算失败。只启动不调用工具不能作为通过依据：只在工具函数里用 `zoneinfo` 的包启动时不报错，调用时才失败。
- 补依赖后重新打包要提升 `pyproject.toml` 的版本号再上传。平台按包名和版本号定位包，同一版本号内容不同的包会被拒绝。
