# 开发文档共用样式

四份开发文档（PRD、方案、制作进度、验收报告）都从下面这段开头起笔，**原样复制**，一个字符都不改；只把 `<title>` 里的【填】换成文档名和应用名。样式只在这里维护，四份文档不另写样式、不改类名、不加 `<link>` 和 `<script>`。

Studio 用不能执行脚本的沙箱显示这些文档，只放行内联样式：展开、收起只能用 `<details>`；进度条、预算条的长度用元素上的 `style="--done:…"` 这类变量控制（见各文档的骨架）。三类步骤四份文档都用同一套类名：人 `human`、模型 `model`、脚本 `rule`。
