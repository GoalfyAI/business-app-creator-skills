背景（FB-1258 / R-572）：旧的公共校验层在更新时把所有字段都当成「可以不传、也可以传 null」，必填字段传 null 会落到数据库 NOT NULL 约束，返回内部错误 1000。新版本更新时字段仍可省略，但必填字段一旦出现就不能是 null 或空串；字段规则新增 `nullable`（缺省允许为空），`nullable: false` 的列在创建和更新时都拒绝 null，提示统一为「<字段标签>不能为空」。

只升级固定层、不补 `nullable: false` 时，必填字段已能正确返回 1001，但 NOT NULL 有默认值的列传 null 仍是 1000，所以本指南把补规则单独列为一步。新生成的路由会自动带上 `nullable: false`。

生成的新建页会把留空的字段发成 null，因此在页面上新建记录时，NOT NULL 有默认值的列留空会返回 1001「不能为空」（修复前是 1000）。需要留空取默认值的，页面上给该字段填默认值或改为不发送该字段。
