# G2 核实资产

确认页里每一步先问「平台上是不是已经有了」：能复用的直接用，只造缺的。这一段只查不建（能力试用包除外）。

## 1. 进入条件

- G1 出口：开发者已确认确认页。
- 从能力试用进来时，按 [../tasks/能力试用.md](../tasks/能力试用.md) 接上本段第 3 步。

## 2. 做什么

1. **逐项查**：

   | 确认页里的 | 去查 | 怎么查 |
   |---|---|---|
   | 规则步骤要调的外部能力（拉数、发送、查询） | 工具组 / 工具集 | `list_assets(asset_type="tool_group", keyword=<平台或动作词>)`，命中后 `get_asset` 看工具名、参数、是否要授权卡 |
   | 模型步骤 | FastAgent | `list_assets(asset_type="fast_agent", keyword=<判读 / 生成 / 诊断 + 领域词>)`，命中后 `get_asset` 看输入字段与输出形状 |
   | 整条路线像已有应用 | 场景包 | `list_assets(asset_type="scenario_package", keyword=…)`，命中后 `get_asset` 看路线与 TPE |
   | 要存的表 | 数据模板 | `list_assets(asset_type="dataset", keyword=…)`；已有模板看列注释里的 `[editable:user|agent|system]` |
   | 页面 | 脚手架预置件 | 读应用工程的 `frontend/registry.json`：三必备页面、入口表单、项目层、表单应答、交付审阅、列表 / 详情 / 表单数据块 |

   `list_assets` 的关键词只匹配名称和 ID，用英文短词试几次；`get_asset` 配置为空且 `can_view_params=false` 是脱敏，不是空资产。
2. **真调一次**：名字对上不算。脚本要直接调用、又拿不准返回的工具，用 `otpe_tool_test(task_id, tool_group_id, tool_id, input=<最小合法参数>)` 取样，看 `structured_content` 是不是确认页要的那个对象，同时核对文件参数收 URL 还是 `/workspace` 路径。**禁止**对删除、发信、发布、涉及资金或凭证、不可逆的工具取样。
3. **判定复用方式**：

   | 情况 | 做法 |
   |---|---|
   | 工具返回覆盖需要 | 直接用；要授权的确认已有授权卡 |
   | FA 输出能覆盖确认页「出什么」 | 直接复用；差一两个字段时 `clone_asset` 后改提示词，不改共享资产 |
   | 官方或他人的场景包 | `clone_asset` 后改；自己的草稿 `ensure_draft` 继续 |
   | 已有模板缺列 | 在工作集里加列再 `extract` 新版本，不另建同义表 |
   | 平台上没有 | 外部有现成 MCP 或 Skill 包：按 [../reference/依赖与MCP接入.md](../reference/依赖与MCP接入.md) 接入；能力是确定性的：写进编排脚本的代码步；需要模型：G4 新建 FA；都不行：写开发需求，交开发者决定改范围还是等 |

4. **缺口处置**：做不成的步骤写清原因、影响哪条功能、建议（换能力、改范围、等平台）。影响确认页内容的，改确认页并告诉开发者改了什么；不影响的直接往下。

## 3. 产出与落盘

- 对照表写进本段阶段文档，并记工单 checkpoint：

  | 确认页里的步骤 | 复用什么（资产 ID） | 取样结论 | 缺什么 / 怎么处置 |
  |---|---|---|---|

- 「缺什么」那一列就是 G3 编译、G4 要造的清单。
- 方案页「开发内容」补「能力来源」：每一步用什么做成，用业务语言写；缺能力、要开发者决定时 `status` 改 `waiting` 并写 `.pv-you`；核实时发现要开发者提供的账号、密钥、数据，补进 `needs`。
- 阶段状态：G2 `passed`，G3 `in_progress`。

## 4. 给开发者看什么

一句话结论：「N 步都有现成能力，M 步要新做，K 步做不成需要你定」；需要他决定的只列做不成的那几步和建议。

## 5. 出口

确认页里每一步都有「复用的资产 ID」或「新建」或「开发者已决定的处置」，没有空行。

## 6. 出问题怎么办

| 现象 | 先看 | 回到 |
|---|---|---|
| 取样报参数错、路径不存在 | 工具当前 Schema 的文件参数说明；换 `file_to_url` 或 `/workspace` 路径 | 本段第 2 步 |
| 工具要最终用户各自授权 | [../reference/依赖与MCP接入.md](../reference/依赖与MCP接入.md) 授权卡一节 | 本段 |
| 资产受限或脱敏 | 告诉开发者，确认后再用 | 本段 |
| 关键步骤做不成、影响主要功能 | 改确认页，重新确认 | G1 |
