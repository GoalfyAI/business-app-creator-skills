# 场景包配置详解（四）：知识文件与 Skill 文本 / 文件分工

要给场景包上传知识 Skill 文件（`知识_*.md`），或判断一段内容放 Skill 文本还是 Skill 文件时读。

本文分 4 份：[场景包配置-名称描述工具集.md](场景包配置-名称描述工具集.md)、[场景包配置-Skill文本.md](场景包配置-Skill文本.md)、[场景包配置-场景文件.md](场景包配置-场景文件.md)、[场景包配置-知识文件与分工.md](场景包配置-知识文件与分工.md)。

### 知识文件

多个场景共用的领域知识，不绑定特定业务流程。

#### 配置范式

> **命名**：`知识_{主题}.md`
> 多个场景共享的参考资料，读者是 SA

> **有 TPE 时**：场景包的知识 Skill 文件对 TA 不可见。如果 TA 也需要某份领域知识，应在 TPE 的 Skill 文件中提供 TA 视角的版本。

适合放的内容：
- 平台规则、限制、配额
- 常见问题诊断和处理方案
- 字段定义、规范标准等参考资料
- 业务规则（审批规则、分级标准等）

#### 合格示例

```markdown
# 审批权限矩阵

## 采购审批
| 金额范围 | 审批人 |
| --- | --- |
| ≤ 5,000 元 | 部门经理 |
| 5,000 - 50,000 元 | 总监 |
| 50,000 - 200,000 元 | VP |
| > 200,000 元 | CEO |

## 人员变动审批
| 变动类型 | 审批人 |
| --- | --- |
| 岗位调整（同部门） | 部门经理 |
| 跨部门调动 | 双方部门经理 + HR |
| 离职 | 部门经理 + HR |

## 特殊规则
- 季度末冻结期内，所有采购审批升一级
- 紧急采购可走快速通道，事后 48 小时内必须补审批
```

```markdown
# 平台退换货政策

## 标准退换规则
| 商品类型 | 退换时限 | 条件 |
| --- | --- | --- |
| 实物商品 | 签收后 7 天内 | 未拆封、不影响二次销售 |
| 虚拟商品 | 不支持退换 | — |
| 定制商品 | 不支持退换 | 质量问题除外 |

## 退款金额规则
- 未发货取消：全额退款
- 已发货退回：扣除实际运费后退款
- 部分退款：按商品单价 × 退货数量计算

## 特殊时期
- 大促期间（双11、618）退换时限延长至 15 天
- 质量问题由商家承担运费
```

### Skill 文本与 Skill 文件的分工

| | Skill 文本 | Skill 文件 |
| --- | --- | --- |
| 加载方式 | 启动时自动注入上下文 | SA 需要时主动读取 |
| 内容长度 | 短、精（始终占上下文） | 长、全（按需读取） |
| 适合放的 | 全局约束、业务路线说明、TPE 路由表、场景索引表、文件指南 | SOP 流程、领域知识、参考资料 |

> **关键**：SA 启动时能看到 Skill 文件的**路径列表**（Skill Directory List 自动拼接在 Skill 文本之后），但看不到文件内容。建议在 Skill 文本中加上场景索引表或文件指南，明确告诉 SA 每个文件包含什么、什么时候去读。如果文件名本身已足够自解释（如 `场景_故障排查.md`、`知识_退款政策.md`），SA 可根据文件名判断何时读取，但显式指南仍是最佳实践。

### 诊断要点

- 场景文件是否按模板编写，步骤是否标注了类型
- 场景文件是否自包含（SA 读一个文件就能执行完整场景）
- 场景文件是否混入了不属于此层级的信息（工具接口描述、FA 内部逻辑、详细领域知识）
- 知识文件是否被多个场景共享（如果只有一个场景用到，考虑放场景文件中）
- 所有 Skill 文件是否都在 Skill 文本中有对应的索引/指南条目（注意：SA 启动时能看到 Skill 文件路径列表，如果文件名已自解释，缺少显式索引可降为 suggestion 级别）
