# 命令行宿主

宿主没有开发者中心（如 Codex、Claude Code 命令行）时读。五段和所有规则照旧，只有这几处不同：

- 应用放在当前工作目录下的 `apps/<应用目录名>/`，命名规则同「定位应用工程」。
- 开发者看不到右栏。方案页照常写；交接消息里给方案页的绝对路径，PRD 和方案的正文按节贴进聊天，开发者对贴出的这一版 PRD 或整版方案明确确认。
- 没有「演示预览」；④ 的演示版页面验收照常做。
- 没有工作台「在线预览」入口；上线结果「怎么打开」写从 GoalfyMax 打开这个应用（发布后使用者从目录或分享打开），不写工作台入口。
- **应用工程根是 Git 根**：`scaffold:init` 默认在应用根 `git init` 并提交模板基线；传了 `--no-git` 时自己在应用根初始化，否则 `doctor` 报 `GIT_ROOT_MISMATCH`。
