# 记下来写什么

③ 写工单 checkpoint、阶段文档 G4 与 G5、交付物时读。

- **工单 checkpoint**：场景包草稿 ID、每个新建资产的 ID 与 `mr_name`、每个 FA 的模型、每条 TPE 的 verify 结论、每条路线的冒泡 `run_id`、是否 `full_run` 与终态、花费；`business_ui_id`、`data_uid`、模板 ID 与版本、`npm run verify` 结果。
- **阶段文档 G4**：资产清单的实际结果与 verify 摘要；每条读写应用库路线的反读自查四项；每次试跑的例子、为什么挑、入口原文、每一步结果、输出原文、`run_id` 与 `project_id`、花费与用时、和预期的对照；开发者拍板的题和答案。
- **阶段文档 G5**：表结构（`inspect` 结果的业务说明）、页面清单的实际结果、界面风格的决定、开发者确认过的页面样子（作修改基线）、「已确认业务含义—界面文案—实际页面或动作」的简短对应（含整体对象、各入口和补充动作、真实产物），不另建文案计划书；待 ④ 回写的示例位置。
- **交付物**：方案页状态写当前进展；`full_run` 或实际跑到终态的才进「已验证」并带证据，桩跑通、只在演示预览里看过的进「未验证」并写明「只用模拟数据跑过」「只在演示预览里看过」；`full_run` 的实际花费补进「费用与副作用」。Studio 宿主下写成「制作进度」开发文档，按 `agenticapp-host-studio`。
