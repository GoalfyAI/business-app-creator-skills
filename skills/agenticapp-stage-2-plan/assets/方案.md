# 整版方案模板

施工单编好、验收条目写完后，照这里一次写出整版方案给开发者确认。方案只有三块：**制作范围 → 运行条件 → 功能与页面**。全文用业务话；用到收费、第三方或要授权的能力时，写出实际的服务名和用途（「用阿里云短信给使用者发到期提醒」）。资产 ID、模型名、路线编号只写进阶段文档 G3。写完对照入口 [平台对象与用词.md](../../agenticapp-creator/references/平台对象与用词.md)「不对开发者说的词」搜一遍，有就改成业务话。

开发者确认方案，就同意了「运行条件」里列的花钱和对外动作；之后做出来、上线都不再问，这是花钱和对外动作唯一的一道确认，所以这五件事要写全，他才知道自己同意了什么。他在生成方案前选过的取舍，在对应那一项后面标「你选的」。

Studio 宿主写成开发文档「方案」，按 `agenticapp-host-studio` 的方案数据。其他宿主写进方案页（`agenticapp-stage-1-requirements`「方案页」）：运行条件进「开发内容」开头，要他准备的同时列进 `#needs`；功能与页面接在后面；和 PRD 不一致的地方标出改动并升版（`agenticapp-tool-workspace`「方案页」）。

## 1. 制作范围

- 这个应用把什么变成什么：2–5 个短语，按顺序（「录批次 → 每天算清单 → 首页看清单」）。
- 做哪些功能和页面、这次不做什么、非刚需这次做不做，两三句。
- 一共要做什么，一句话：几个功能、几个页面、存几样东西。
- 信息架构，三项各带一句业务理由：导航项与顺序（按使用者完成业务的顺序）、主工作区（打开应用先看到的那一块）、信息优先级（同一屏里先看什么）。开发者给了界面答案的照它写；说「你看着办」或没说过的，由你按这个业务的使用顺序和每天最先要处理的事写出来，不写「按默认」。例：「导航：线索池 → 跟进中 → 已成交（按销售推进的顺序）；主工作区：今日待跟进；优先级：逾期 > 今日 > 本周（销售每天先处理逾期）」。

## 2. 运行条件：五件事

每件写**现在的情况**和**影响什么**；没定的再写成他能答的问题，不写「待确认」。已经定了的不另起一句复述，现状里没说到的结论（如花费上限）才补一句。

| 五件事 | 写什么 |
|---|---|
| 数据从哪来、多久更新 | 从哪个平台拿什么、多久更新一次；只用使用者录的写「只用你在应用里录的」 |
| 要准备什么账号、谁授权 | 要他提供的材料、账号、授权、数据分享：每样用在哪一步、缺了影响什么；要使用者各自授权的写明（`agenticapp-tool-integration`「授权卡」）。不请他把密码、密钥发在聊天里 |
| 哪些地方花钱 | 制作还要花多少（还要试跑的份数 × 每份）；上线后每用一次约多少、按用量每周约多少；和花费上限比（超了的在发方案前已出过选择题，写他选了什么）；会调用的收费工具；失败重试会不会再扣 |
| 谁能看、谁能改、存多久 | 平台没有团队，每个使用者用自己的一份；哪些记录使用者能改、哪些只能看；上传的资料和生成的结果保存多久、能不能删 |
| 会不会自动对外做事 | 自动发生的事（到点、有新记录时）；会写入或发出去什么，没有写「不会向外发送任何东西」；资料交给哪些外部服务、会不会公开，没有写「不交给外部服务」 |

花费的数：实测过的写实测；拿不到实测的按 `agenticapp-ref-platform-limits`「已知数字」估，标「估算」并写出乘法（「每次约 3 积分 × 每周 20 次」）。

## 3. 功能与页面

每个刚需一节，按使用顺序：

| 内容 | 写什么 |
|---|---|
| 完成什么业务 | 一句话 |
| 怎么完成 | 按什么顺序、用什么数据、每一步谁来做；哪一步要人把关。后台按规则处理的，逐条写清三件：每条结果标出引用的原文位置（哪份资料、第几页或哪一行），只附原文不算；同一份再算一次时，新结果覆盖旧的还是另存一版；上传和生成的文件留多久 |
| 页面 | 按 ① 问到的界面答案（参考、第一眼看到什么、整体感觉）和制作范围里的信息架构，写这一页放什么、怎么排。方案确认后，这里和信息架构就是页面的最高依据（`agenticapp-tool-frontend`「先定样子」） |

Studio 下每个功能另做一个可以点的完整页面示例，配编号说明。

## 验收条目（不进方案正文）

照 [../references/验收条目.md](../references/验收条目.md) 写，每条标「AI 能判断」或「要人判断」。Studio 下存进 `acceptance.json`；其他宿主记进阶段文档 G3。方案里只写条数，④ 照它逐条测。

## 交接消息

```text
【② 方案 → 等你确认】
刚做完：整版方案第 1 版：做 2 个功能、3 个页面；运行条件五件事写清了，要你准备 1 样（门店的收银导出表）；制作还要约 120 积分（估算：每份约 4 积分 × 30 份），在上限 500 以内；不会向外发送任何东西。验收条目 9 条，想看就说。
下一步：这是最后一次请你确认。你确认后我开始制作，做完放到在线预览并上线，再用真实数据验收，把验收报告交给你。
要你做的：看这一版方案，没问题就确认；哪里要改直接说。确认就表示同意上面写的花费和对外动作。
花了多少：这一阶段 0 积分；一共 60；上限 500。
```
