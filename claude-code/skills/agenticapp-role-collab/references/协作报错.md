# 协作相关报错

工具返回下面的错误码时读。加人、改档、移除的报错见 [加人改档移人.md](加人改档移人.md)。

| 错误码 | 含义 | 处置 |
|---|---|---|
| `BUSINESS_UI_FINALIZE_OWNER_ONLY`、`BUSINESS_UI_COLLABORATION_OWNER_ONLY` | 协作者调了上线、发布、下线（`offline`）、删除（`delete`）、再分享这类属主动作 | 告诉开发者这些只能由属主操作；不重试、不换工具绕。要上线就用 `request_finalize` 提请属主上线，要下线或删除请开发者联系属主 |
| `BUSINESS_UI_COLLABORATION_FORBIDDEN` | 没有权限：不是协作者、已被移除、只读协作者做写操作，或改的是别人创建的草稿 | 重读 `role`；只读的按 `agenticapp-task-diagnose` 做；换回自己的草稿。`reason=account_inactive` 表示账号已停用，如实告诉开发者，不重试 |
| `BUSINESS_UI_COLLABORATION_READ_ONLY` | 只读协作者写数据 | 不重试；要改请属主升档 |
| `PERSONAL_VERSION_NOT_OWNER`（查询时） | 协作者用 `list_asset_versions` 查属主名下的场景包、工具集、FA 等资产；这个工具对智能应用以外的资产只给资产属主 | 改用 `get_asset` 看版本，草稿以 `ensure_editable_asset_draft` 的返回为准。这不是档位问题，不请属主升档 |
| `PERSONAL_VERSION_NOT_OWNER`（写入时） | 只读协作者建草稿或改资产 | 不重试；要改请属主升档 |
| `TEMPLATE_WORKSPACE_WRITER_FORBIDDEN` | 只读协作者 `connect` 没带 `mode="reader"` 或申请了写连接 | 改用 `connect(mode="reader")` 只读查询，不写表、不改结构 |
| `CHANGE_NOTE_REQUIRED` | 建应用草稿没带变更说明 | 见 `agenticapp-tool-deploy` 报错的「上线与下线」 |
| `BUSINESS_UI_COLLABORATION_ASSET_NOT_OWNER_OWNED` | 编辑协作者往属主的应用里挂记在自己名下的资产 | 带 `collaboration_business_ui_id` 重新创建，或用 `clone_asset` 带该参数复制到属主名下，再挂新资产；只用这两条路 |
| `PERSONAL_VERSION_STALE_SOURCE` | 草稿基线已过期 | 协作者按 SKILL.md「基线过期的合并」合并新版本；属主告诉提请人先合并 |
| `TEMPLATE_BASELINE_REQUIRED`、`TEMPLATE_BASELINE_CHANGED` | 抽模板没带基线，或别人已先抽出新版本 | 按 `agenticapp-tool-data-template` 的常见错误处理；别人加的结构保留 |
| `BUSINESS_UI_FINALIZE_REQUEST_NOT_READY` | 提请的草稿还没有部署成功 | 回 ④ 把这份草稿 `ship` 到 `success` 后再提请 |
| `BUSINESS_UI_FINALIZE_REQUEST_OWNER_SELF` | 属主自己提请 | 不用提请，直接按 `agenticapp-stage-5-launch` 上线 |
| `BUSINESS_UI_COLLAB_PREVIEW_SCAFFOLD_OUTDATED`、`BUSINESS_UI_RECHARGE_OWNER_ONLY` | 旧模板部署、广告充值 | 预期限制，见 [预览费用与限制.md](预览费用与限制.md) |
