# 只读协作者能读什么

开发者是只读协作者（`role=viewer`）时读。他不管要做什么都按 `agenticapp-task-diagnose` 做，用 read 工单，只用下面列出的读取。

## 可以用的读取

| 要看什么 | 用什么 |
|---|---|
| 版本、草稿和部署记录 | `business_ui_manage(action="get")` |
| 应用代码 | `business_ui_bundle(action="get" / "download")` 下载源码包读 |
| 运行记录 | 对 `get` 返回的属主预览项目（`data.owner_preview_projects`）调 `get_project_execution_logs` |
| 使用者反馈 | `business_ui_feedback` 的 `list`、`get`（只查询、只出报告） |
| 场景包、工具集、FA 等各层资产 | `get_asset` 看详情和版本，`compare_asset_versions` 比较版本 |
| 开发库结构 | `dataset_template_workspace(action="inspect")` |
| 开发库数据 | `dataset_template_workspace(action="connect", mode="reader")` 取只读连接，只执行 SELECT |

- `connect` 必须显式带 `mode="reader"`：不带时缺省是写连接。返回 `TEMPLATE_WORKSPACE_WRITER_FORBIDDEN`，或因为工单是只读模式被拒（`WORKFLOW_TASK_MODE_MISMATCH`），都改用 `mode="reader"` 重调，不为此新开 write 工单。
- 看属主名下资产的版本一律用 `get_asset`；调 `list_asset_versions` 被拒的原因见 [协作报错.md](协作报错.md) 的 `PERSONAL_VERSION_NOT_OWNER`。

## 不做的

- 派生任何草稿（`ensure_draft`、`update`、`ensure_editable_asset_draft`）；
- `connect` 申请写连接（`mode="writer"` 或不带 `mode`）；执行写数据的 SQL 或 DDL；
- 跑 `ship`、部署、冒泡、实际跑这类写流程；调 `finalize` 或 `request_finalize`；
- 处理使用者反馈（改状态、按反馈改应用）；
- 新建或克隆资产；
- 用 `dataset_read` 读应用开发库：它只读长期数据集，查开发库会被拒。

## 预览

只读协作者的预览页面只读，保存类按钮禁用并显示原因。在预览里提交表单、保存等写入被拒是预期结果，不是故障。

## 他要改应用时

告诉他改动要请属主或编辑协作者做：请属主把他升为编辑协作者后按修订改，或把诊断报告交给属主或编辑协作者去改。
