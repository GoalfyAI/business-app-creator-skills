# 编排型 TPE 正反例索引

任务涉及 `parallel`、`pipeline`、文件产物、handoff、降级，或 Preview / Hub / Runtime 报了对应错误，要找该读哪份正反例时读。

案例只用于说明 [单编排型 TPE 制作契约](单编排型TPE契约-脚本Schema与事件.md) 和 [多编排型 TPE 制作契约](多编排型TPE契约-图模型与标准对象.md) 已定义的契约，不是第二份规范。如果案例与实时 Tool Schema、Preview、Hub 或 Runtime 冲突，以机器真值为准并修正案例。

不要在每个任务开始时通读全部案例：

```text
任务涉及该能力 → 制作前读对应正例
校验或运行出现该类错误 → 修复时读对应反例
普通线性编排型 TPE → 不读无关案例
```

| 案例 | 何时读取 | 覆盖范围 | 不可复制的内容 |
