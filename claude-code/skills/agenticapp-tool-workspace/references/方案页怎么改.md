# 方案页怎么改

发交接消息、改方案页内容、出新一版方案页时读。方案页是什么、样式和校验在 SKILL.md「方案页」；内容和版式怎么写见 `agenticapp-stage-1-requirements`「方案页」。

- **什么时候更新状态块**：每发一条交接消息，同时更新方案页的状态块（开头状态、刚做完、要你做的、当前工作区阶段）；各段要写成什么见那一段 Skill 的「记下来」。
- **改动标记**：相对上一版改过的词句用 `<mark class="pv-changed">` 包住，旧高亮在下一版去掉。
- **出新版**：先把当前页复制成 `docs/proposal/history/v<当前版本>.html`，副本里 `href="proposal.css"` 改成 `href="../proposal.css"`；再改 `index.html`，`data-version` 加一，`.pv-meta` 链到上一版。旧版只存不改。做成：`docs/proposal/history/v<当前版本>.html` 存在且引用 `../proposal.css`，`index.html` 的 `data-version` 比它大 1，`npm run doctor` 没有 `FAIL`。
