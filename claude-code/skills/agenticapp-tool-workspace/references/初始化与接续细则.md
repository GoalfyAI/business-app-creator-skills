# 初始化与接续细则

新建时 `scaffold:init` 报「缺少环境」、接续一个协作者工作区里没有的应用、已有应用、或没有 PRD 的应用时读。主干步骤在 SKILL.md「初始化或接续工作区」。

## 新建

- `scaffold:init` 只有它报「缺少环境」时，才问开发者在哪个 GoalfyMax 站点开发，答案原样填进 `--environment` 再初始化。这道题怎么出见 `agenticapp-stage-1-requirements`「开始前的几种情况」，在第一轮里编作 Q1。加 `--without-demo-pack` 就不带示例包。
- 写方案页最小草案时：Studio 宿主下不另传文档模式参数，草案记进阶段文档 G1，按 `agenticapp-host-studio`。

应用走新 SDK 还是旧路（`frontend/goalfy-app.json` 的 `executor`）由当前脚手架模板决定，不手工给旧模板加 `executor` 或删掉它。

## 接续

接在 SKILL.md「接续」第 1、2 步之后：

1. 协作者工作区里没有应用工程：`business_ui_bundle(action="download")` 取最新上线版（或自己要接着改的草稿）的源码包，解压到 `apps/<应用目录>/`，再做第 2 步。
2. 已有应用先 `business_ui_manage(action="get")` 看 `role`、待上线的提请、自己草稿的基线是否过期，按 `agenticapp-role-collab` 处理完再接本轮改动。
3. 没有 PRD 的应用：已经上线的加载 `agenticapp-task-revise`；还没上线的先把已有材料补成 PRD 差异版（补上谁来用、每一步谁来做、花费上限和用量），请开发者确认一次再从对应的段接上。工作区已有的方案页不删除、不改写。
