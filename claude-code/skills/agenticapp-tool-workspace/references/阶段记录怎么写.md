# 阶段记录怎么写

调 `business_ui_stage` 时读。什么时候写、写失败怎么办在 SKILL.md「阶段记录」。

```text
business_ui_stage(task_id="wft_xxx", stage="G1", result="passed",
  completion="PRD 第 2 版已确认：1 张借用记录表、首页+登记页，开发者回复「确认这一版」",
  next_stage="G2", reason="PRD 已确认，边问边核实的结论要整理进 G2",
  next_plan="把借阅系统工具组的核实对照表写进 G2")
```

- **现在到哪**：`stage` 填刚结束的那一项（G1–G7）；`result` 取 `passed` / `partial` / `failed`（和阶段标记的对应见 [三件套与阶段标记.md](三件套与阶段标记.md)「两套取值」）。
- **完成得怎样**：`completion` 写做出了什么、交棒条件逐项是否满足；遗留问题写 `open_issues`；证据指针（部署编号、checkpoint、版本号）放 `evidence`。
- **为什么往下走**：`next_stage` 填下一项（结单填 `closeout`），`reason` 写为什么现在进它，`next_plan` 写下一项打算做什么（结单传空串）；跳过的项写进 `skipped`，每个给理由。
