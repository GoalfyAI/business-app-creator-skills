# 首屏与导航

写首页、排导航、设计空库表现、放示例数据前读。

按使用者要完成的事组织，不按功能模块或平台对象组织：

- **首页是业务工作台**：打开就回答「现在情况怎样、为什么、下一步做什么」——业务目标或关键数字、支撑它的依据、一个最该点的下一步；待办与最近结果放旁边。首屏不被通用列表、运行状态或空白占位主导。
- **导航顺序 = 使用者完成业务的顺序**（如「建档 → 诊断 → 处理建议 → 复盘」），名称用业务词；按方案信息架构的导航顺序重排默认导航。
- **空库与日常分开设计**：每个使用者从空库开始，首页和各列表页都要有空库引导；第一次要先建档、授权或导入的，引导去做；有数据后首页回到日常工作台。上线后必须有的设定放哪见 `agenticapp-tool-data-template`「预览数据不进正式版」。
- **示例数据连到业务**：能解释业务目标、展示一份完整成果、能接着点下一步；不放「测试 1」「foo」，界面上标明是示例。
- **不露平台信息**：mock 标记、运行状态细节、日志、阶段、数据集名称不放在使用者界面上。

## 常见错误

| 错误 | 正确做法 |
|---|---|
| 空库时首页一片空白，每个使用者第一次打开都从空库开始，看到的就是这片空白 | 做空库引导 |
