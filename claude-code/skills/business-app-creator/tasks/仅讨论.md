# 仅讨论

## 识别信号

- 纯概念咨询（「场景包是什么」「编排型 TPE 和普通任务点有什么区别」）。
- 开放讨论，没指向当前工作台里的具体应用。
- 开发者明确要求只在聊天里回答、不写文件。

## 先读什么

- 概念问题读 [../reference/平台对象速查.md](../reference/平台对象速查.md)；平台契约问题用 `get_diagnosis_doc(topic=…)`（这一步需要工单时建 read 工单）。
- 不读工作区、不查资产，除非回答需要一个具体事实。

## 从哪一段进

不进五段：不建 write 工单、不初始化应用、不创建平台资产，对话答复即可。

- 讨论落到当前工作台里的具体应用（「这个应用该怎么做」「先出个方案」）时属于新建或接续：按 [../SKILL.md](../SKILL.md)「开工」做，至少写出交付物的最小草案（方案页；Studio 下记进阶段文档 G1），本轮只做到 ① 的 PRD；开发者明确说只在聊天里回答时遵从。
- 开发者要深入梳理业务、还不急着做应用时，按 [../design/咨询模式.md](../design/咨询模式.md) 做。
- 只讨论方案不自动授权实现、部署或上线。
