# 咨询模式（可选）

只有开发者明确要求「帮我先理一理业务」「不确定该做什么」时才进。它不是制作前置，做完仍回到分工表。

做法：

1. 读开发者给的材料（SOP、截图、参考项目），列出你看到的角色、动作、判断点和交付物，不加推测。
2. 用一张表给开发者看：现在人工怎么做（步骤、谁做、耗时、常出错的地方），标出哪些步骤能交给规则、哪些需要模型、哪些必须留给人。
3. 把开发者选定要做的部分直接写成分工表，进 [`确认页.md`](./确认页.md)。

访谈时一次只问一组相关问题，每组先给你的理解和默认做法，让开发者改而不是从零答；问到能写出分工表为止。

不做：价值论证、样品挑选、承诺清单、计划书。
