# 咨询模式（可选）

只有开发者明确要求「帮我先理一理业务」「不确定该做什么」时才进。它不是制作前置，做完仍回到 PRD 的「谁来用」和「每一步谁来做」。

做法：

1. 读开发者给的材料（SOP、截图、参考项目），列出你看到的角色、动作、判断点和交付物，不加推测。
2. 用一张表给开发者看：现在人工怎么做（步骤、谁做、耗时、常出错的地方），标出哪些步骤能交给脚本、哪些需要模型、哪些必须留给人；现在由别人做的步骤，按 [谁来做.md](./谁来做.md)「谁来用」写成使用者自己的一步或放进「这次不做的」。
3. 把开发者选定要做的部分直接写成「谁来用」和「每一步谁来做」（[谁来做.md](./谁来做.md)），进 [PRD.md](./PRD.md)。

问法按 [按轮问.md](./按轮问.md)：每轮问现在就能问的全部问题，每题先给你的理解和推荐做法，让开发者改而不是从零答；已定的不再问，问到能写出这两节为止。

咨询的产出只有这两节，不另写价值论证、样品挑选、承诺清单或计划书。
