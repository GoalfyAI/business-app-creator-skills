# 3.1 核实资产能力

目的：分工表里每一行先问「平台上是不是已经有了」，能复用的直接用，只造缺的。这一步只查不建。

## 查什么

| 分工表里的 | 去查 | 怎么查 |
|---|---|---|
| 规则行要调的外部能力（拉数、发送、查询） | 工具组 / 工具集 | `list_assets(asset_type="tool_group", keyword=<平台或动作词>)`，命中后 `get_asset(asset_type="tool_group", asset_ids=[…])` 看工具名、参数、是否要授权卡 |
| 模型行 | FastAgent | `list_assets(asset_type="fast_agent", keyword=<判读 / 生成 / 诊断 + 领域词>)`，命中后 `get_asset` 看它的输入字段与输出形状 |
| 整条路线像已有应用 | 场景包 | `list_assets(asset_type="scenario_package", keyword=…)`，命中后 `get_asset(asset_type="scenario_package", asset_ids=[…])` 看路线与 TPE；官方包可 `clone_asset` 后改 |
| 进出物要存的表 | 数据模板 | `list_assets(asset_type="dataset", keyword=…)`；已有模板看列注释里的 `[editable:user|agent|system]` |
| 页面 | 脚手架预置件 | 读应用工程里的 `frontend/registry.json`：三必备页面、入口表单、项目层、表单应答、交付审阅、列表 / 详情 / 表单数据块都已有 |

## 复用判定

- 工具：名字对上不算，**真调一次**：`otpe_tool_test(task_id, tool_group_id, tool_id, input=<最小合法参数>)`，看 `structured_content` 是不是分工表要的那个对象。要授权的工具确认已有授权卡（`create_auth_card` 只在没有时建）。
- FA：输出形状能覆盖分工表「出什么」就复用；差一两个字段时优先 `clone_asset` 后改提示词，不改共享资产。
- 场景包：官方或他人的包一律 `clone_asset` 再改；自己的草稿直接 `ensure_draft` 继续。
- 表：已有模板缺列就在工作集里加列再 `extract` 新版本，不另建同义表。

## 产出

一张对照表记进工单（`task_manager insert, entry_type="checkpoint"`）：

| 分工表行 | 复用什么（资产 ID） | 缺什么 |
|---|---|---|

「缺什么」那一列就是 3.2 要造的清单。
